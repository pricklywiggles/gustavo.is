## Text on dark ground

Body copy is Pale Dune on Dusk Earth. **Bold text** stays on the same step, *italics* lean without changing color, and inline code like `pnpm run dev` sits in a small ink chip.

> A quote reads as a traditional pull quote: led by a Noon Sun mark, no card, no hairline, body a step larger than the running text.

## Code

A single fenced block with a title:

```ts title="verify.ts"
type Check = { name: string; passed: boolean };

export function summarize(checks: Check[]): string {
	const failed = checks.filter((check) => !check.passed);
	if (failed.length === 0) return "all green";
	return `${failed.length} of ${checks.length} failed`;
}
```

Consecutive fences with tab labels become one tabbed block:

```ts tab="TypeScript"
export function greet(name: string): string {
	return `Hello, ${name}!`;
}
```

